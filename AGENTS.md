# Just Simple Planner

- Follow the project-root AGENTS.md. Test only in the canonical @Nexus-dev vault.
- Independent plugin. Do not change the other plugins to implement planner features.
- Source notes and demo filenames are Spanish; property keys, UI and configuration are English.
- A card is one ordinary Markdown note. Folders never determine presentation or thread membership.
- No network requests or runtime dependencies. Never store note bodies only in plugin data.json.
- Run npm run check, install and verify through the root installer, then inspect in Obsidian.
- The demo generator is additive and refuses to overwrite a differing existing fixture.
- Do not publish, create a remote or make a release unless requested.
