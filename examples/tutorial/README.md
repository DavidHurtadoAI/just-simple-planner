# Tutorial starter pack

Follow the [illustrated tutorial](https://github.com/DavidHurtadoAI/just-simple-planner/blob/main/docs/TUTORIAL.md). All projects, notes and tasks in this pack are fictional. Note names and content are Spanish; the tutorial and plugin controls are English.

1. Install Just Simple Planner 0.5.6 or later and enable Obsidian's core **Bases** plugin.
2. Copy the entire `Planner tutorial` folder into the **root of your existing vault**. Keep that folder name: the Base filters refer to it. If that destination already exists, use the existing copy or rename both the folder and the Base filters deliberately; do not overwrite your own notes.
3. Open `Planner tutorial/Primeros pasos/Primer planner.base`.
4. Use the planner's **Go to date** field to select **2026-11-09**. The dates are fixed so the written walkthrough and screenshots match, even when you read this later.
5. You should see **five entries, two thread rows and four connections**. One connection crosses between threads. **Tasks** shows five pending checkboxes.
6. Open `Planner tutorial/Avanzado/Planner avanzado.base` for a multi-day note, a weekly review and a note with additional dates. It reads three source entries and the same two linked thread notes.

The pack contains ordinary `.md` notes and `.base` view definitions. It has no vault configuration, plugin files, scripts or separate task database. It does not require another community plugin.

The two Bases select different folders through their own filters. Folder scope selects notes; the `thread` property determines which row contains a card. You can reorganize files later by updating those filters.

The initial snapshot is intentionally unfinished. Experiment with dragging, connections, tasks and Undo. **Remove note from planner…** removes the shared entry marker; it keeps the file. Deleting a Markdown file in Obsidian deletes that source note.
